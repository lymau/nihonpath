# [M5-1] Sentry, metrik klien, analitik dengan consent

**Milestone:** M5 — Observability, Hardening, Beta Tertutup  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M5-1` — Sentry, metrik klien, analitik dengan consent
- **Tujuan:** Mengintegrasikan Sentry Flutter dengan scrubbing PII ketat, metrik performa kustom klien, dan pelacakan taksonomi analitik PostHog berbasis izin pengguna (consent).
- **Bagian Dokumen Acuan:** §5.2 (sentry_flutter), §10.5 (Observability sisi klien), §10.6 (Analitik produk), §12.2 (Persetujuan privasi UU PDP & GDPR)
- **Input:** Konfigurasi DSN Sentry dan API Key PostHog, taksonomi event §10.6.
- **Output:** Module telemetri di `apps/mobile/lib/core/telemetry/` dan integrasi di `main.dart`.

### Langkah Implementasi
1. Integrasikan SDK Sentry Flutter (`sentry_flutter`) di `main.dart`:
2.   - Tangkap crash, ANR, unhandled exception, dan flutter error dengan breadcrumb navigasi.
3.   - Aktifkan release health tracking untuk mengukur crash-free sessions.
4.   - Pasang trace performa: cold start aplikasi, latensi transisi review card, dan durasi sync.
5.   - Scrubbing PII ketat: WAJIB set `sendDefaultPii = false` dan filter URL/teks sebelum dikirim (§10.5).
6. Implementasikan pengiriman metrik kustom sisi klien (sampling 100%) sebagai event analitik (§10.5):
7.   `sync_attempt{result, duration_ms}`, `outbox_depth` (di akhir sesi), `pack_download{result, size, duration_ms}`, `db_migration{result, from, to}`, `review_card_render_ms` (p50/p95).
8. Integrasikan analitik PostHog dengan manajemen consent privasi (§10.5, §12.2):
9.   - Analitik HANYA aktif jika pengguna telah memberikan persetujuan eksplisit di layar onboarding.
10.   - Terapkan taksonomi event ketat berformat snake_case tanpa teks bebas (§10.6): `app_open`, `onboarding_completed`, `lesson_started`, `lesson_completed`, `review_session_started`, `review_session_completed {cards, accuracy, duration_s}`, `daily_goal_met`, `streak_extended`, `pack_downloaded`, `paywall_viewed`, `subscription_started`, `mocktest_completed`, `settings_changed`.

### Tes yang Harus Ada
- [ ] Unit test: verifikasi Sentry interceptor menghapus data PII (email, input bebas) dari breadcrumb dan exception payload.
- [ ] Widget test: pelacakan analitik diblokir sepenuhnya jika consent pengguna bernilai false.
- [ ] Integration test: penyelesaian sesi review memancarkan event `review_session_completed` dengan metrik cards, accuracy, dan duration_s.

### Observability yang Harus Ada
- [ ] Dashboard Sentry menerima error crash uji coba dan release health.
- [ ] Dashboard PostHog menerima taksonomi event sesuai spesifikasi.

### Di Luar Cakupan (Out of Scope)
- Alerting Prometheus di backend (dikerjakan di M5-2).
- A/B testing fitur tingkat lanjut.
