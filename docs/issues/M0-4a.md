**Area:** `infra`

## Task Brief

- **Task ID / Judul:** `M0-4a` — Terraform Jaringan & Layanan Container Dev
- **Tujuan:** Menyusun modul Terraform untuk jaringan (VPC, Subnet multi-AZ) dan runtime container layanan API dan Worker di environment dev.
- **Bagian Dokumen Acuan:** §4.2 (Pilihan teknologi), §11.2 (Tangga skala tahap 1), §14.1, §14.2
- **Input:** Arsitektur cloud dev di Region Jakarta (AWS ap-southeast-3 / GCP asia-southeast2).
- **Output:** Modul Terraform di `infra/terraform/modules/network` dan `infra/terraform/modules/compute` beserta environment dev `infra/terraform/environments/dev`.

### Langkah Implementasi
1. Konfigurasi remote state backend Terraform (S3/GCS bucket dengan state locking).
2. Tulis modul Terraform untuk VPC, private subnet multi-AZ, public subnet, NAT Gateway, dan Security Groups di Region Jakarta.
3. Tulis modul Terraform untuk layanan compute container (Cloud Run / AWS ECS Fargate / K8s terkelola) untuk API (autoscale CPU 60%) dan 1 worker BullMQ.
4. Setup IAM role dengan prinsip Least Privilege untuk service container.
5. Konfigurasi variable dan environment dev di `infra/terraform/environments/dev`.
