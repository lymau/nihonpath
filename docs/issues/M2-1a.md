## Task Brief

- **Task ID / Judul:** `M2-1a` — CLI Ingest JMdict & KANJIDIC2
- **Tujuan:** Mengembangkan modul CLI tools/content-cli untuk mem-parsing data JMdict dan KANJIDIC2 serta menyimpannya ke kolam kandidat konten dengan metadata lisensi CC BY-SA 4.0.
- **Bagian Dokumen Acuan:** §3.2 (Sumber data dan lisensi), §9.1 tahap 1 (Ingest), §14.1 (tools/content-cli)
- **Input:** File XML sumber JMdict dan KANJIDIC2 (EDRDG).
- **Output:** CLI command `nihon-content ingest jmdict` dan `nihon-content ingest kanjidic` yang menghasilkan file YAML di `content/_pool/vocab/` dan `content/_pool/kanji/`.

### Langkah Implementasi
1. Buat command line tool di `tools/content-cli/` menggunakan TypeScript / Node.js.
2. Implementasikan XML streaming parser untuk JMdict: ekstrak ID entri, pembacaan kana, kanji, part-of-speech (pos), serta arti dalam bahasa Indonesia dan Inggris.
3. Implementasikan XML streaming parser untuk KANJIDIC2: ekstrak karakter kanji, makna (meaning), on'yomi, kun'yomi, dan jumlah goresan (stroke count).
4. Format output ke file YAML terstruktur dengan metadata atribusi lisensi CC BY-SA 4.0 (§3.2, §9.2): `source: [{name: JMdict/KANJIDIC2, license: CC-BY-SA-4.0}]`.
5. Simpan kandidat item ke dalam `content/_pool/vocab/` dan `content/_pool/kanji/` dengan penamaan `external_key` stabil (mis. `vocab:jmdict:1358280`, `kanji:食`).

### Tes yang Harus Ada
- [ ] Unit test: parser JMdict berhasil mengekstrak entri vocab kompleks (multiple readings & meanings).
- [ ] Unit test: parser KANJIDIC2 mengekstrak kanji beserta goresan dan on/kun.
- [ ] Verifikasi output YAML menyertakan blok metadata `source` dan `license` lengkap.

### Observability yang Harus Ada
- [ ] Log proses ingest mencatat jumlah total entri diproses, error parsing, dan waktu eksekusi.
