# [M2-1c] CLI Pool Manager & Pemetaan Level JLPT Komunitas

**Milestone:** M2 — Content Pipeline dan Konten Awal  
**Estimasi Ukuran:** M  
**Area:** `content`  

---

## Task Brief

- **Task ID / Judul:** `M2-1c` — CLI Pool Manager & Pemetaan Level JLPT Komunitas
- **Tujuan:** Mengembangkan modul CLI tools/content-cli untuk memetakan kolam kandidat konten ke level perkiraan JLPT (Tanos) dan frekuensi kata (wordfreq).
- **Bagian Dokumen Acuan:** §2 (Frekuensi dan lexical coverage), §3.1 (Cakupan per level), §3.2 (Lisensi komunitas), §9.1 tahap 2 (Kurasi)
- **Input:** Kolam konten `content/_pool`, daftar level JLPT komunitas (Tanos), pustaka `wordfreq`.
- **Output:** CLI command `nihon-content pool map-level` dan metadata level/frekuensi pada item di `content/_pool`.

### Langkah Implementasi
1. Integrasikan daftar pemetaan level JLPT komunitas (mis. daftar Tanos, CC BY) ke dalam CLI.
2. Integrasikan pustaka kalkulasi frekuensi leksikal bahasa Jepang (`wordfreq`).
3. Buat algoritma penandaan item: setiap kosakata dan kanji di `content/_pool` diberi estimasi level JLPT (0, 5, 4, 3, 2, 1) serta skor frekuensi penggunaan riil (§2, §3.1).
4. Sediakan utilitas CLI untuk memfilter dan mengurutkan kandidat kosakata berdasarkan level lalu frekuensi guna mempermudah pemilihan silabus oleh content lead (§2, §9.1 tahap 2).

### Tes yang Harus Ada
- [ ] Unit test: verifikasi kosakata dasar (misal `食べる`, `行く`) terpetakan ke Level 5 (N5) dengan skor frekuensi tinggi.
- [ ] Unit test: ketiadaan duplikasi `external_key` saat pemetaan dilakukan.

### Observability yang Harus Ada
- [ ] Log statistik distribusi jumlah kata dan kanji per level (0, N5 s/d N1).
