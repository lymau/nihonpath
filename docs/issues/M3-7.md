# [M3-7] Alur pelajaran (perkenalan, kuis, ringkasan)

**Milestone:** M3 — Flutter Inti (Offline)  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M3-7` — Alur pelajaran (perkenalan, kuis, ringkasan)
- **Tujuan:** Mengimplementasikan layar alur pelajaran /lesson/:id yang mencakup tahap perkenalan, kuis retrieval interaktif, pencatatan kartu pertama ke SRS, dan ringkasan hasil.
- **Bagian Dokumen Acuan:** §2 (Retrieval practice), §3.3 (Hierarki lesson), §3.5 (Alur pelajaran 4 langkah), §5.3 (/lesson/:id)
- **Input:** Data pelajaran dari tabel `lessons` dan `lesson_items`.
- **Output:** Layar `/lesson/:id` di `apps/mobile/lib/features/lesson/` dan lesson coordinator provider.

### Langkah Implementasi
1. Buat layar rute `/lesson/:id` menggunakan `FScaffold` Forui (§5.2.1).
2. Tahap 1 (Perkenalan): tampilkan 3–5 item baru per layar; sertakan teks kata/kanji, audio otomatis, contoh kalimat dengan furigana, dan ilustrasi/mnemonik singkat. Tombol 'Lanjut' mengarah ke item berikutnya (§3.5).
3. Tahap 2 (Kuis Langsung / Retrieval): setelah perkenalan, setiap item baru ditanyakan dalam kuis aktif hingga dijawab benar minimal satu kali (tidak ada mode hafalan baca-saja, §2, §3.5).
4. Tahap 3 (Masuk SRS): setiap jawaban kuis otomatis dicatat sebagai `review_log` pertama; kartu dimasukkan ke `user_cards` dengan status `Learning` (state=1) dan jadwal interval dari FSRS (§3.5).
5. Tahap 4 (Ringkasan): tampilkan kartu `FCard` ringkasan hasil: daftar item yang dipelajari, akurasi, dan estimasi beban review untuk esok hari (§3.5).
6. Simpan progres kelulusan pelajaran ke tabel `lesson_progress` (status='completed', best_score) dan masukkan entri ke outbox sync.

### Tes yang Harus Ada
- [ ] Integration test: alur lengkap pelajaran (perkenalan -> kuis -> ringkasan) berhasil diselesaikan.
- [ ] Unit test: kuis retrieval berulang menanyakan item sampai pengguna menjawab benar.
- [ ] Unit test: penyelesaian kuis otomatis membuat kartu SRS baru di `user_cards` dengan status Learning dan mencatat review_log perdana.
- [ ] Unit test: record `lesson_progress` diperbarui dengan benar.

### Observability yang Harus Ada
- [ ] Event analitik produk: `lesson_started` dan `lesson_completed` dipancarkan (§10.6).
- [ ] Log INFO saat pelajaran selesai.

### Di Luar Cakupan (Out of Scope)
- Latihan membaca bertingkat (dikerjakan di M6-3).
- Sinkronisasi outbox progress ke backend (dikerjakan di M4-2).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ DILARANG mode baca-saja untuk hafalan; kuis retrieval WAJIB ada langsung setelah materi (§2).
- ⚠️ Setiap item yang lulus kuis WAJIB langsung mencatat review log pertama dan kartu SRS berstatus Learning (§3.5).
- ⚠️ Komponen visual wajib menggunakan Forui widgets (`FScaffold`, `FCard`, `FButton`) (§5.2.1).
