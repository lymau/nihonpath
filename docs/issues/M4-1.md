**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M4-1` — Klien API ter-generate + alur auth + secure storage + refresh otomatis
- **Tujuan:** Mengintegrasikan klien API Dio hasil generate openapi, penyimpanan token aman di flutter_secure_storage, dan interceptor auto-refresh token singleton.
- **Bagian Dokumen Acuan:** §4.2 (flutter_secure_storage, dio), §8.1 (Header & Error), §8.3 (Autentikasi & Rotasi token), §12.1 (Pencegahan token theft)
- **Input:** Klien Dio ter-generate dari M0-2, endpoint auth dari M1-3 & M1-4.
- **Output:** Auth repository di `apps/mobile/lib/data/auth/`, Dio interceptor di `lib/data/api/`, dan secure token storage service.

### Langkah Implementasi
1. Integrasikan klien `Dio` hasil generasi otomatis dari kontrak `openapi.yaml` (dilarang menulis model klien API manual! §0 Aturan 2, §8.1).
2. Implementasikan `TokenStorage` menggunakan `flutter_secure_storage` untuk menyimpan JWT access token, refresh token, dan `device_id` (UUIDv7) secara terenkripsi di Keychain (iOS) dan EncryptedSharedPreferences (Android).
3. Buat Dio Interceptor untuk menyematkan header wajib di setiap request outgoing (§8.1):
4.   - `Authorization: Bearer <jwt>`
5.   - `X-Device-Id: <device_id>`
6.   - `X-App-Version: <version>`
7.   - `traceparent`: header W3C Trace Context yang digenerate oleh klien agar trace tersambung end-to-end ke backend (§8.1, §10.4).
8. Implementasikan Interceptor penanganan token kedaluwarsa (HTTP 401):
9.   - Kunci request (singleton lock / queue) agar ketika ada banyak request paralel yang menerima 401, pemanggilan rotasi `POST /v1/auth/refresh` HANYA DILAKUKAN SEKALI (§15, M4-1).
10.   - Simpan pasangan token baru yang dirotasi ke secure storage dan ulangi request yang tertunda.
11.   - Jika server merespons error refresh (misal `AUTH_REFRESH_REUSED` atau token expired), hapus seluruh token dari storage dan arahkan pengguna ke login kembali.

### Tes yang Harus Ada
- [ ] Unit test: request otomatis menyertakan header Authorization, X-Device-Id, X-App-Version, dan traceparent.

- [ ] Unit test: secure storage menyimpan dan membaca token dengan aman.
