## Task Brief

- **Task ID / Judul:** `M5-4` — Checklist MASVS L1 + tinjauan keamanan
- **Tujuan:** Melakukan audit keamanan menyeluruh sesuai OWASP Mobile Application Security Verification Standard (MASVS) L1, pemindaian dependensi, SAST, dan secret scanning.
- **Bagian Dokumen Acuan:** §12.1 (Ancaman utama dan kontrol lengkap), §14.3 (CI security scanning)
- **Input:** Codebase backend dan mobile, tool pemindaian (CodeQL, Semgrep, Trivy, Gitleaks, OSV-Scanner).
- **Output:** Dokumen hasil audit di `docs/security/masvs-l1-checklist.md` dan pipeline security scanning di CI.

### Langkah Implementasi
1. Jalankan checklist OWASP MASVS L1 (Level 1) pada aplikasi Flutter (§12.1):
2.   - Konfigurasi code obfuscation dan R8 pada build rilis Android.
3.   - Verifikasi seluruh token disimpan di Keychain / EncryptedSharedPreferences (bukan file plain text).
4.   - Verifikasi tidak ada logging data sensitif atau PII saat build mode release aktif.
5.   - Verifikasi seluruh komunikasi jaringan dipaksa menggunakan TLS 1.2+ (diutamakan 1.3) dan HSTS.
6. Konfigurasi security scanning otomatis di pipeline CI (.github/workflows/security.yml):
7.   - Secret scanning dengan Gitleaks untuk mencegah commit kunci rahasia.
8.   - Software Supply Chain audit: lockfile verification, Dependabot, OSV-Scanner, dan `npm audit` (§12.1).
9.   - Static Application Security Testing (SAST) menggunakan CodeQL atau Semgrep.
10.   - Pemindaian kontainer docker menggunakan Trivy.
11. Pastikan kriteria terpenuhi: TEMUAN LEVEL TINGGI / KRITIS (HIGH/CRITICAL) HARUS 0 (§15, M5-4).

### Tes yang Harus Ada
- [ ] Eksekusi pipeline CI security scan lulus dengan 0 temuan berstatus Critical dan High.
- [ ] Verifikasi file APK/IPA release terbukti diobfuskasi (analisis dekompilasi).
- [ ] Verifikasi header HSTS dan penolakan koneksi TLS di bawah versi 1.2 pada server.

### Observability yang Harus Ada
- [ ] Laporan security scan terbit pada tab GitHub Security / Actions.

### Di Luar Cakupan (Out of Scope)
- Certificate Pinning (eksplisit TIDAK dipakai di MVP karena risiko operasional sesuai §12.1).
- MASVS L2 / hardware-backed keystore biometrik.

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ Temuan keamanan High/Critical WAJIB 0 (§15, M5-4).
- ⚠️ Certificate pinning TIDAK DIPAKAI di MVP (§12.1).
- ⚠️ Role database aplikasi dilarang memiliki hak DDL (§12.1).
