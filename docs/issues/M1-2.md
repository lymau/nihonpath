## Task Brief

- **Task ID / Judul:** `M1-2` — Migrasi 001 (seluruh skema §6.3) + Kysely typed
- **Tujuan:** Mengimplementasikan migrasi SQL murni lengkap untuk seluruh skema PostgreSQL (§6.3) beserta partisi review_logs dan tipe Kysely.
- **Bagian Dokumen Acuan:** §4.2 (Kysely + node-pg-migrate), §6.3 (Skema PostgreSQL lengkap), §11.3 (Migrasi)
- **Input:** Skema DDL PostgreSQL di §6.3 dokumen teknis.
- **Output:** File migrasi SQL murni di `apps/api/src/db/migrations/`, tipe Kysely di `apps/api/src/db/types.ts`, dan instance Kysely pool di `apps/api/src/db/client.ts`.

### Langkah Implementasi
1. Tulis file migrasi SQL murni `001_initial_schema.sql` (menggunakan node-pg-migrate):
2.   - Ekstensi `citext`.
3.   - Tabel `users`, `auth_identities`, `devices`, `refresh_tokens` (dengan index `user_id, family_id`).
4.   - Tabel `content_items` (index `jlpt_level, type`), `lessons`, `lesson_items`, `content_packs`.
5.   - Tabel `user_sync_state`, `user_cards` (index `user_id, user_seq`), `user_settings`, `lesson_progress`, `test_attempts`, `subscriptions`.
6.   - Tabel `review_logs` yang terpartisi: `PARTITION BY RANGE (reviewed_at)` dengan indeks `(user_id, user_seq)` dan `(user_id, card_id, reviewed_at)`.
7.   - Buat partisi default awal `review_logs_default` sebagai pengaman partisi.
8. Tulis langkah migrasi turun (`down`) yang membersihkan seluruh tabel secara atomik.
9. Generate tipe TypeScript Kysely dari skema database.
10. Konfigurasi connection pool Kysely ke PostgreSQL dengan `statement_timeout` 3 detik (§11.3) dan role aplikasi tanpa hak DDL (§12.1).
