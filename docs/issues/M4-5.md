# [M4-5] Tautkan guest, hapus akun, ekspor data (UI)

**Milestone:** M4 — Auth dan Sync Klien  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M4-5` — Tautkan guest, hapus akun, ekspor data (UI)
- **Tujuan:** Mengimplementasikan antarmuka UI di Flutter untuk menautkan akun guest ke akun permanen (Google/Apple/Email), dialog konfirmasi hapus akun, dan permintaan ekspor data.
- **Bagian Dokumen Acuan:** §5.3 (/settings, tautan akun), §7.4 (Guest -> akun), §8.2, §12.2 (Penghapusan akun & ekspor data UI)
- **Input:** Endpoint `/v1/auth/link`, `DELETE /v1/me`, `POST /v1/me/export` dari M1-4 dan M1-5.
- **Output:** Widget antarmuka di `apps/mobile/lib/features/settings/` (`account_settings.dart`, `link_account_dialog.dart`, `delete_account_dialog.dart`).

### Langkah Implementasi
1. Implementasikan UI Tautkan Akun di Pengaturan:
2.   - Tombol tautkan akun dengan Google Sign-In, Sign in with Apple, dan Email OTP.
3.   - Panggil endpoint `POST /v1/auth/link` (§7.4, §8.2).
4.   - Jika identitas sudah dimiliki akun lain (terjadi konflik), tampilkan dialog peringatan eksplisit kepada pengguna untuk memilih akun yang dipertahankan (MVP tidak melakukan auto-merge data, §7.4).
5. Implementasikan UI Hapus Akun (§12.2):
6.   - Tombol 'Hapus Akun' dengan dialog konfirmasi ganda yang menjelaskan konsekuensi penghapusan permanen.
7.   - Panggil endpoint `DELETE /v1/me`; setelah sukses, bersihkan seluruh secure storage token, reset database SQLite lokal, dan arahkan pengguna kembali ke onboarding.
8. Implementasikan UI Ekspor Data (§12.2):
9.   - Tombol 'Ekspor Data Belajar' di menu pengaturan; panggil `POST /v1/me/export`.
10.   - Tampilkan notifikasi dengan tautan unduh bertanda tangan setelah file siap diunduh.

### Tes yang Harus Ada
- [ ] Widget test: dialog konfirmasi penghapusan akun tampil dengan peringatan yang jelas.
- [ ] Integration test (staging): alur tautkan akun guest ke Google/Apple berhasil memperbarui identitas tanpa kehilangan progres belajar.
- [ ] Integration test: penghapusan akun berhasil memanggil API dan membersihkan storage lokal.

### Observability yang Harus Ada
- [ ] Event analitik produk: `settings_changed` dicatat.
- [ ] Log INFO saat alur penautan akun atau penghapusan akun dipicu.

### Di Luar Cakupan (Out of Scope)
- Fitur merge otomatis antar 2 akun berbeda (di luar lingkup MVP sesuai §7.4).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ Tombol Hapus Akun WAJIB ada di dalam aplikasi (aturan wajib App Store & Google Play, §5.3, §12.2, §16.3).
- ⚠️ Jika tautan akun konflik, DILARANG merge data diam-diam tanpa persetujuan eksplisit pengguna (§7.4).
