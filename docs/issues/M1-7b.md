## Task Brief

- **Task ID / Judul:** `M1-7b` — Sync Pull (GET /v1/sync/pull) & Cursor Pagination
- **Tujuan:** Mengimplementasikan endpoint pull sinkronisasi dengan kueri UNION ALL terurut user_seq, filter origin device, dan paginasi cursor gapless.
- **Bagian Dokumen Acuan:** §6.3 (user_cards, review_logs, user_settings, lesson_progress, test_attempts), §7.2 (GET /v1/sync/pull), Lampiran C.3 (Handler pull server)
- **Input:** Query parameters `cursor`, `limit` (max 500), `entities`, header `X-Device-Id`, Kysely pool.
- **Output:** Endpoint `GET /v1/sync/pull` di `apps/api/src/modules/sync/`.

### Langkah Implementasi
1. Ambil parameter request: `cursor` (integer), `limit` (default/max 500), dan `entities` (filter daftar entitas).
2. Bentuk kueri database UNION ALL dari tabel: `user_cards`, `review_logs`, `user_settings`, `lesson_progress`, `test_attempts` dengan kondisi:
3.   `WHERE user_id = $1 AND user_seq > cursor AND (origin_device_id/device_id != $deviceId) AND entitas_dipilih`
4.   `ORDER BY user_seq ASC LIMIT limit + 1` (§7.2, Lampiran C.3).
5. Evaluasi: `has_more = rows.length > limit`; potong baris ke batas `limit`.
6. Hitung `next_cursor`: jika `has_more == true`, next_cursor = seq baris terakhir yang dikembalikan; jika tidak, next_cursor = max(cursor, last_seq milik pengguna) (§7.2, Lampiran C.3).
7. Penting (§7.2, Lampiran C.3): jika baris terfilter milik perangkat peminta memenuhi seluruh halaman, query harus terus berlanjut hingga terkumpul `limit` baris atau data habis, sehingga cursor tetap maju dan klien tidak menerima halaman kosong berulang.
8. Kembalikan response: `{ changes: [{seq, entity, data}], next_cursor, has_more, server_time }`.

### Tes yang Harus Ada
- [ ] Integration test: pull mengembalikan perubahan dengan `user_seq > cursor` secara terurut menaik.
- [ ] Integration test: perubahan yang berasal dari `device_id` yang sama difilter keluar (tidak dikirim balik ke pembuatnya).
- [ ] Integration test: verifikasi cursor tetap maju meskipun seluruh baris pada rentang tersebut berasal dari device peminta.
- [ ] Integration test: verifikasi flag `has_more` dan paginasi cursor bertahap.
