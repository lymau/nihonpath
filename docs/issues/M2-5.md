## Task Brief

- **Task ID / Judul:** `M2-5` — Konten Level 0 (kana): audio, goresan
- **Tujuan:** Menyusun seluruh konten Level 0 (Hiragana & Katakana) lengkap dengan audio 2 suara, goresan KanjiVG, facet pengenalan & penulisan, serta tinjauan manusia 100%.
- **Bagian Dokumen Acuan:** §3.1 (Level 0 Kana), §3.3 (Hierarki konten), §3.4 (Facet kana), §9.1, §9.2
- **Input:** Dataset karakter Hiragana & Katakana, goresan KanjiVG, generator audio M2-4.
- **Output:** Dataset YAML kurikulum Level 0 di `content/level0/` dengan status `human_reviewed`.

### Langkah Implementasi
1. Susun silabus Level 0 lengkap: Hiragana dan Katakana standar (46 karakter masing-masing), dakuten, handakuten, yōon (kombinasi), serta konsep mora dasar (§3.1).
2. Petakan SVG urutan goresan KanjiVG untuk setiap karakter kana ke direktori asset strokes.
3. Generate file audio pengucapan pra-render (suara perempuan dan laki-laki) untuk seluruh mora menggunakan pipeline M2-4.
4. Definisikan facet SRS Level 0 sesuai §3.4: facet `recognition` (pilih romaji/suara) dan facet `writing` (latihan tulis tangan).
5. Lakukan review manusia oleh reviewer bersertifikat (level N2 atau lebih tinggi); ubah status seluruh item menjadi `provenance: human_reviewed` dan isi atribut `reviewed_by` (§9.1 tahap 4).
6. Jalankan validator `nihon-content validate` dan pastikan seluruh konten Level 0 lolos validasi 100%.
