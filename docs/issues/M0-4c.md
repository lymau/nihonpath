## Task Brief

- **Task ID / Judul:** `M0-4c` — Terraform Storage, CDN & Secret Management Dev
- **Tujuan:** Menyusun modul Terraform untuk Object Storage paket konten/audio, CDN, dan Secret Manager di environment dev.
- **Bagian Dokumen Acuan:** §4.2 (Object storage & CDN), §9.3 (Distribusi paket), §12.1 (Keamanan kredensial)
- **Input:** Kebutuhan distribusi paket konten §9.3 dan kebutuhan secret backend §12.1.
- **Output:** Modul Terraform di `infra/terraform/modules/storage` dan `infra/terraform/modules/cdn`.

### Langkah Implementasi
1. Tulis modul Terraform untuk S3-compatible Object Storage bucket dengan versioning aktif untuk content packs dan audio pra-render.
2. Tulis modul CDN (Cloudflare atau AWS CloudFront) yang mengarah ke Object Storage dengan aturan caching read-mostly.
3. Konfigurasi signed URL / presigned URL mechanism untuk bucket storage paket premium (§8.2, §12.1).
4. Tulis modul KMS / Secret Manager untuk rotasi kunci penandatanganan JWT (ES256/EdDSA) dan API keys pihak ketiga.
5. Integrasikan modul storage dan CDN ke `infra/terraform/environments/dev`.

### Tes yang Harus Ada
- [x] Eksekusi `terraform validate` dan `terraform plan` sukses.
- [x] Verifikasi permission bucket privat: akses langsung tanpa CDN / presigned URL ditolak (403 Forbidden).

### Observability yang Harus Ada
- [x] Metrik akses CDN dan HTTP status code logging.

### Di Luar Cakupan (Out of Scope)

- Implementasi endpoint billing verifikasi (dikerjakan di M6-1).
