# [M1-9] Job pembuat partisi + alert partisi DEFAULT

**Milestone:** M1 — Backend Inti  
**Estimasi Ukuran:** S  
**Area:** `backend`  

---

## Task Brief

- **Task ID / Judul:** `M1-9` — Job pembuat partisi + alert partisi DEFAULT
- **Tujuan:** Mengimplementasikan job terjadwal otomatisasi pembuatan partisi bulanan review_logs dan sistem alert jika partisi default terisi.
- **Bagian Dokumen Acuan:** §6.3 (Manajemen partisi), §10.3 (partition_default_rows), §10.7 (Alerting)
- **Input:** Tabel terpartisi `review_logs`, worker BullMQ / scheduler.
- **Output:** Job BullMQ di `apps/api/src/jobs/partition.job.ts` dan aturan alert Prometheus.

### Langkah Implementasi
1. Implementasikan job terjadwal bulanan menggunakan BullMQ / cron internal:
2.   - Query memeriksa partisi tabel `review_logs` yang ada.
3.   - Otomatis buat tabel partisi bulanan `review_logs_YYYY_MM` untuk rentang 3 bulan ke depan (§6.3) menggunakan DDL SQL `CREATE TABLE IF NOT EXISTS review_logs_YYYY_MM PARTITION OF review_logs FOR VALUES FROM (...) TO (...)`.
4. Buat mekanisme query berkala yang menghitung jumlah baris di partisi pengaman `review_logs_default`.
5. Perbarui gauge Prometheus `partition_default_rows` dengan jumlah baris tersebut (§10.3).
6. Buat alert Prometheus rule: picu alert dengan tingkat keparahan tinggi jika `partition_default_rows > 0` (§10.7).

### Tes yang Harus Ada
- [ ] Integration test di Testcontainers: job dieksekusi dan berhasil membuat partisi untuk 3 bulan ke depan.
- [ ] Integration test: baris yang masuk di luar partisi terbuat dialihkan ke partisi default dan nilai `partition_default_rows` bertambah.

### Observability yang Harus Ada
- [ ] Gauge `partition_default_rows` terpantau di Prometheus.
- [ ] Alert terpicu jika baris masuk ke partisi default.

### Di Luar Cakupan (Out of Scope)
- Pengarsipan partisi lama (> 18 bulan) ke Parquet (fase lanjutan sesuai §6.3).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ Partisi bulanan wajib selalu tersedia minimal 3 bulan ke depan (§6.3).
- ⚠️ Alert WAJIB menyala jika ada baris yang masuk ke partisi DEFAULT (§6.3, §10.7).
