# [M3-9] Kana: tabel, latihan, tulis tangan (ML Kit) + animasi goresan

**Milestone:** M3 — Flutter Inti (Offline)  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M3-9` — Kana: tabel, latihan, tulis tangan (ML Kit) + animasi goresan
- **Tujuan:** Mengimplementasikan layar /kana yang memuat tabel Hiragana/Katakana interaktif, animasi goresan SVG StrokeOrderPlayer, dan kanvas latihan tulis tangan HandwritingCanvas dengan ML Kit Digital Ink Recognition.
- **Bagian Dokumen Acuan:** §3.1 (Level 0 Kana), §3.4 (Facet kana), §5.2 (google_mlkit_digital_ink_recognition, flutter_svg), §5.2.1, §5.3 (/kana), §5.5 (Tulisan tangan)
- **Input:** Aset konten Level 0 (audio mora, SVG KanjiVG, model ML Kit bahasa Jepang 'ja').
- **Output:** Layar `/kana` di `apps/mobile/lib/features/kana/`, komponen `StrokeOrderPlayer`, dan `HandwritingCanvas`.

### Langkah Implementasi
1. Buat antarmuka tabel kana interaktif (Hiragana & Katakana) dengan tata letak grid sentuh menggunakan Forui (§5.2.1).
2. Mengetuk karakter kana memutar audio pelafalan mora menggunakan `just_audio`.
3. Buat komponen kustom `StrokeOrderPlayer`: menganimasikan urutan goresan pena dari file SVG KanjiVG menggunakan `flutter_svg` dan timer goresan (§5.5).
4. Buat komponen kustom `HandwritingCanvas`: kanvas interaktif berbasis `CustomPainter` untuk menangkap goresan tangan pengguna.
5. Integrasikan Google ML Kit Digital Ink Recognition (`google_mlkit_digital_ink_recognition`):
6.   - Unduh model bahasa Jepang (`ja`) sekali saat pertama kali fitur dibuka, lalu simpan di disk lokal.
7.   - Eksekusi pengenalan goresan tangan 100% on-device (bekerja tanpa internet) (§5.5).
8. Bandingkan karakter hasil pengenalan goresan tangan dengan karakter target kana; berikan feedback visual instan.

### Tes yang Harus Ada
- [ ] Widget test: tabel kana dapat beralih antara Hiragana dan Katakana dengan audio player terhubung.
- [ ] Widget test: `StrokeOrderPlayer` me-render path SVG dan menjalankan animasi goresan berurutan.
- [ ] Integration test (on-device): `HandwritingCanvas` berhasil mengenali karakter kana yang digambar tangan secara offline menggunakan model ML Kit.

### Observability yang Harus Ada
- [ ] Log INFO saat model ML Kit bahasa Jepang berhasil diunduh dan diinisialisasi.
