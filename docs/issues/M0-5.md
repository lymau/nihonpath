## Task Brief

- **Task ID / Judul:** `M0-5` — Template decision log, ADR, runbook
- **Tujuan:** Menyiapkan template standar dokumentasi teknis: decision-log.md, ADR, dan runbook operasional.
- **Bagian Dokumen Acuan:** §0 Aturan 1 & 8, §10.7 (Runbook), §14.1 (Struktur docs)
- **Input:** Format decision log §0 Aturan 1 dan struktur runbook §10.7.
- **Output:** File `docs/decision-log.md`, `docs/adr/0000-template.md`, dan `docs/runbooks/TEMPLATE.md`.

### Langkah Implementasi
1. Buat `docs/decision-log.md` dengan format baku: Tanggal, Konteks, Keputusan, Alasan (§0 Aturan 1) dan sertakan contoh entri.
2. Buat template ADR di `docs/adr/0000-template.md` (Konteks, Pilihan Keputusan, Keputusan Terpilih, Konsekuensi).
3. Buat template runbook di `docs/runbooks/TEMPLATE.md` yang memuat struktur wajib §10.7: Dampak, Diagnosis 5 langkah, Mitigasi, Eskalasi.
4. Sertakan panduan bagi implementer bahwa setiap asumsi atau pemilihan opsi B wajib dicatat di decision log.
