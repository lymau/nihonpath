# [M4-2a] Outbox DAO & Queue Manager Klien

**Milestone:** M4 — Auth dan Sync Klien  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M4-2a` — Outbox DAO & Queue Manager Klien
- **Tujuan:** Mengimplementasikan Outbox DAO lokal Drift, queue manager mutasi data pengguna, debouncing sinkronisasi 5 detik, dan isolasi batch maksimal 200 op.
- **Bagian Dokumen Acuan:** §4.3 (Prinsip outbox), §6.2 (Tabel outbox), §7.1 (Push berbasis outbox), §7.2 (Batas batch), Lampiran C.1 (requestSync debounce)
- **Input:** Tabel Drift `outbox` dari M3-2.
- **Output:** Class `OutboxDao` dan `OutboxManager` di `apps/mobile/lib/data/sync/`.

### Langkah Implementasi
1. Implementasikan `OutboxDao` untuk menyimpan mutasi data pengguna ke tabel `outbox`:
2.   Kolom: `op_id` (UUIDv7 PK), `type` (`review_log`, `card_state`, `settings`, `lesson_progress`, `test_attempt`), `payload_json`, `created_at`, `attempts`, `next_attempt_at`, `last_error` (§6.2).
3. Setiap perubahan lokal (review, perubahan pengaturan, progres) wajib menulis entri `outbox` dalam TRANSAKSI YANG SAMA dengan mutasi tabel data terkait (§7.1, Lampiran C.1).
4. Implementasikan debouncing: picu notifikasi sinkronisasi dengan debounce 5 detik saat review/belajar sedang berlangsung (§5.4, §7.4, Lampiran C.1).
5. Implementasikan fungsi pembacaan antrean: ambil entri outbox dengan kondisi `WHERE next_attempt_at <= now ORDER BY created_at ASC LIMIT 200` (§7.2, §7.4).
6. Pastikan total payload batch tidak melebihi batas 512 KB (§7.2).

### Tes yang Harus Ada
- [ ] Unit test: penulisan data review otomatis menyisipkan record ke tabel `outbox` dalam transaksi atomik.
- [ ] Unit test: batch builder membatasi maksimal 200 operasi dan tidak melebihi 512 KB.
- [ ] Unit test: mekanisme debounce 5 detik berhasil menunda pemanggilan sync saat operasi berturut-turut masuk.

### Observability yang Harus Ada
- [ ] Metrik sisi klien `outbox_depth` dicatat saat sesi belajar selesai (§10.5).

### Di Luar Cakupan (Out of Scope)

- Merge data masuk dari pull (dikerjakan di M4-2c).
