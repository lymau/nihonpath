## Task Brief

- **Task ID / Judul:** `M3-1` — Kerangka app: flavor, Forui preset ajeneb, AppColors, l10n id/en, Clock, IdGenerator, router
- **Tujuan:** Membangun kerangka dasar aplikasi Flutter feature-first dengan Forui UI (preset ajeneb), go_router, Riverpod, token AppColors, Noto Sans JP, l10n id/en, Clock, IdGenerator, dan 3 flavors.
- **Bagian Dokumen Acuan:** §4.2 (Pilihan mobile), §5.1 (Struktur feature-first), §5.2 (Paket diizinkan), §5.2.1 (Forui preset ajeneb), §5.5 (Font Noto Sans JP), §5.6 (Aksesibilitas & l10n)
- **Input:** Spesifikasi UI dan arsitektur client di `apps/mobile/`.
- **Output:** Struktur direktori `apps/mobile/lib/`, file `app.dart`, `main.dart`, `lib/theme/`, `lib/core/` (Clock, IdGenerator), dan konfigurasi router.

### Langkah Implementasi
1. Inisialisasi aplikasi Flutter di `apps/mobile/` dengan struktur feature-first persis sesuai §5.1 (`core/`, `data/`, `domain/`, `features/`, `l10n/`, `ui/`, `lib/theme/`).
2. Jalankan setup UI library Forui (§5.2.1):
3.   `flutter pub add forui`
4.   `dart run forui init --preset ajeneb --template=router`
5. Catat hasil kode warna inti, radius, dan font bawaan preset `ajeneb` di `docs/decision-log.md` beserta tangkapan layar tema terang dan gelap (§5.2.1). (Jika kode ditolak CLI, catat blocker dan fallback ke `FTheme.neutral`).
6. Konfigurasi `app.dart` menyatukan Forui + `go_router` (`routerProvider`) + Riverpod (`MaterialApp.router` dengan `FTheme`, `FToaster`, `FTooltipGroup`, §5.2.1).
7. Definisikan `ThemeExtension` `AppColors` di `lib/theme/` untuk token khusus aplikasi: warna rating SRS (`Again`, `Hard`, `Good`, `Easy`), warna furigana, dan status benar/salah, diakses lewat `context.theme.colors.app` (§5.2.1).
8. Ubah `_display` dan `_body` di `typography.dart` untuk menggunakan font Noto Sans JP hasil subset pyftsubset (§5.5) dengan fallback ke font sistem.
9. Buat abstraksi `Clock` (interface `Clock { DateTime now(); }`) dan `IdGenerator` (UUIDv7 untuk data pengguna dan UUIDv5 deterministik untuk card_id, §3.4, §5.1, §6.1). Dilarang memakai `DateTime.now()` mentah di logika bisnis!
10. Setup 3 Flutter flavors (`dev`, `staging`, `prod`) menggunakan `--dart-define` dan lokalisasi ARB untuk bahasa Indonesia (`id`) dan Inggris (`en`) (§5.6).

### Tes yang Harus Ada
- [ ] Aplikasi Flutter dapat di-build dan berjalan lancar di 3 flavor (dev, staging, prod).
- [ ] Widget test: tema Forui terang dan gelap ter-render dengan benar beserta token AppColors.
- [ ] Unit test: verifikasi IdGenerator menghasilkan UUIDv7 valid dan UUIDv5 deterministik untuk card_id.
- [ ] Unit test: Clock abstraction dapat di-mock untuk simulasi waktu.
