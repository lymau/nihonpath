# [M0-4b] Terraform Data Stores Dev (PostgreSQL & Redis HA)

**Milestone:** M0 — Fondasi  
**Estimasi Ukuran:** M  
**Area:** `infra`

## Task Brief

- **Task ID / Judul:** `M0-4b` — Terraform Data Stores Dev (PostgreSQL & Redis HA)
- **Tujuan:** Menyusun modul Terraform untuk provisioning database PostgreSQL primary HA multi-AZ dengan replica dan Redis HA di environment dev.
- **Bagian Dokumen Acuan:** §4.2 (Postgres 16+, Redis), §11.2 (Tangga skala 1), §11.4 (Backup & PITR)
- **Input:** Modul jaringan dari M0-4a.
- **Output:** Modul Terraform di `infra/terraform/modules/database` dan integrasinya di `infra/terraform/environments/dev`.

### Langkah Implementasi
1. Tulis modul Terraform untuk PostgreSQL terkelola HA multi-AZ (versi minimal 16) dengan 1 read replica.
2. Konfigurasi PgBouncer dalam mode transaction untuk connection pooling (§11.2).
3. Konfigurasi backup otomatis: Point-In-Time Recovery (PITR) kontinu, retensi 14 hari, dan replikasi backup snapshot lintas region ke Singapura (§11.4).
4. Tulis modul Terraform untuk Redis terkelola HA (multi-AZ) untuk cache, rate limit, dan BullMQ.
5. Integrasikan credential database dan Redis ke Secret Manager / KMS terkelola.

### Tes yang Harus Ada
- [x] Eksekusi `terraform validate` dan `terraform plan` untuk modul database sukses.
- [x] Uji konektivitas PgBouncer dan verifikasi parameter `statement_timeout` 3 detik (§11.3).

### Observability yang Harus Ada
- [x] Metrik CPU, memori, disk, dan koneksi DB diekspor ke cloud monitoring.

### Di Luar Cakupan (Out of Scope)
- Eksekusi migrasi skema tabel (dikerjakan di M1-2).
- Konfigurasi compute container (dikerjakan di M0-4a).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ PostgreSQL wajib primary HA multi-AZ + 1 replica (§11.2).
- ⚠️ PITR kontinu dengan retensi 14 hari dan salinan lintas region Singapura wajib dikonfigurasi (§11.4).
- ⚠️ RPO target ≤ 5 menit, RTO ≤ 1 jam (§11.4).
