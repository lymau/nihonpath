# [M3-3a] Content Pack Downloader (Range Resume & Verifikasi SHA-256)

**Milestone:** M3 — Flutter Inti (Offline)  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M3-3a` — Content Pack Downloader (Range Resume & Verifikasi SHA-256)
- **Tujuan:** Mengimplementasikan download manager paket konten di Flutter dengan kemampuan resume (HTTP Range), pelacakan progres, dan verifikasi checksum SHA-256.
- **Bagian Dokumen Acuan:** §5.2 (dio, crypto), §9.3 (Anggaran ukuran dan distribusi), §11.3 (Degradasi CDN)
- **Input:** Endpoint manifest dan download-url dari backend NestJS.
- **Output:** Class `ContentPackDownloader` di `apps/mobile/lib/data/content_pack/`.

### Langkah Implementasi
1. Implementasikan pengunduh file paket zip menggunakan `Dio` dengan dukungan header HTTP Range untuk melanjutkan (resume) unduhan yang terputus (§9.3).
2. Sediakan stream progres unduhan (persentase, kecepatan, bytes transferred) untuk dihubungkan ke UI.
3. Sediakan opsi pengaturan pengguna: opsi mengunduh paket audio hanya saat terhubung jaringan Wi-Fi (§9.3).
4. Implementasikan verifikasi integritas file: hitung hash SHA-256 file zip yang diunduh menggunakan paket `crypto` dan cocokkan dengan hash dari manifest sebelum proses instalasi dimulai (§5.2, §9.3).
5. Jika checksum tidak cocok, hapus file korup dan kembalikan error verifikasi yang dapat di-retry.

### Tes yang Harus Ada
- [ ] Unit test: verifikasi checksum SHA-256 berhasil mencocokkan hash yang valid dan menolak file korup.
- [ ] Integration test (mock HTTP): simulasi unduhan terputus di 50% dan berhasil di-resume dengan header Range.
- [ ] Unit test: flag 'hanya Wi-Fi' mencegah pengunduhan audio pada koneksi seluler.

### Observability yang Harus Ada
- [ ] Metrik event analitik: `pack_download{result, size, duration_ms}` (§10.5).
- [ ] Logging INFO saat unduhan dimulai, berhasil diverifikasi, atau gagal.

### Di Luar Cakupan (Out of Scope)

- UI download tile (dikerjakan di M3-8/M3-10).
