## Task Brief

- **Task ID / Judul:** `M5-2` — Dashboard, alert burn-rate, runbook (§10.7)
- **Tujuan:** Mengonfigurasi dashboard Grafana lengkap, sistem alerting berbasis multi-window multi-burn-rate pada Alertmanager, serta menyusun dokumen runbook operasional.
- **Bagian Dokumen Acuan:** §10.3 (Metrik penamaan Prometheus), §10.7 (SLO, alert, dashboard, runbook), §11.3
- **Input:** Metrik Prometheus backend dan server OTel Collector.
- **Output:** Konfigurasi Prometheus alert rules, dashboard Grafana JSON di `infra/grafana/`, dan dokumen runbook di `docs/runbooks/*.md`.

### Langkah Implementasi
1. Buat 7 Dashboard Grafana wajib sesuai spesifikasi §10.7:
2.   1. Service Overview (RED metrics: Rate, Errors, Duration per route).
3.   2. Sync Health (push ops, batch size, pull latency, rejection, clock anomalies).
4.   3. Database Health (koneksi, pool in use/waiting, slow queries, partisi).
5.   4. Queue & Worker (BullMQ queue depth, job duration, failed jobs).
6.   5. Authentication (login rate per provider, refresh reuse detection spike).
7.   6. Learning Outcomes (true retention, leech rate, due backlog median).
8.   7. Client Release Health (crash-free rate, client sync success rate).
9. Konfigurasi aturan alert Alertmanager berbasis multi-window multi-burn-rate (§10.7):
10.   - Alert PAGE (kritis): konsumsi error budget 14,4x pada window 1 jam dan 5 menit (anggaran error habis dalam 2 hari).
11.   - Alert TICKET (peringatan): konsumsi error budget 6x pada window 6 jam dan 30 menit.
12.   - Alert Infrastruktur: CPU DB > 80% (15 menit), koneksi DB > 80%, replication lag > 30s, disk > 80%, queue depth tinggi selama 10 menit, `partition_default_rows > 0`, lonjakan reuse token, backup gagal, sertifikat kedaluwarsa < 14 hari, 5xx rate > 2% selama 5 menit.
13. Tulis dokumen runbook di `docs/runbooks/<nama_alert>.md` untuk setiap alert: wajib memuat Dampak, Diagnosis 5 langkah, Mitigasi, dan Eskalasi (§10.7).
14. Uji coba pemicuan alert secara sengaja (fire drill) untuk membuktikan alert dan runbook berfungsi.

### Tes yang Harus Ada
