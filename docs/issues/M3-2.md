# [M3-2] Skema SQLite klien (Drift) + DAO + tes migrasi

**Milestone:** M3 — Flutter Inti (Offline)  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M3-2` — Skema SQLite klien (Drift) + DAO + tes migrasi
- **Tujuan:** Mengimplementasikan skema database SQLite klien menggunakan Drift, Data Access Objects (DAO), indeks query performa, dan pengujian migrasi bertingkat.
- **Bagian Dokumen Acuan:** §4.2 (Drift di atas SQLite), §5.1 (data/), §6.1 (Konvensi ID & status), §6.2 (Skema SQLite klien lengkap)
- **Input:** Tabel skema SQLite klien di §6.2 dokumen teknis.
- **Output:** File database Drift di `apps/mobile/lib/data/db/` (`app_database.dart`, tabel, DAOs, skema migrasi).

### Langkah Implementasi
1. Definisikan tabel Drift lengkap sesuai §6.2:
2.   - `content_items` (id, external_key UNIQUE, type, jlpt_level, payload_json, content_version)
3.   - `lessons`, `lesson_items`
4.   - `user_cards` (card_id PK, item_external_key, facet, state, due, stability, difficulty, elapsed_days, scheduled_days, reps, lapses, step, last_review_at, suspended, buried_until, updated_at) dengan INDEKS WAJIB `(state, due)` dan `(item_external_key)` (§5.6, §6.2).
5.   - `review_logs` (id PK, card_id, rating, state_before, reviewed_at, duration_ms, scheduled_days, elapsed_days, stability_before, difficulty_before, exercise_type) bersifat append-only.
6.   - `user_settings`, `lesson_progress`, `test_attempts`, `outbox`, `sync_state`, `pack_state`.
7. Implementasikan virtual table FTS5 `fts_items` pada kolom kana, kanji, romaji, dan arti (§5.5, §6.2).
8. Implementasikan DAOs terpisah untuk setiap area data dengan query typed dan stream reaktif.
9. Konfigurasi strategi migrasi Drift (`MigrationStrategy`) dan pastikan PRAGMA foreign_keys aktif.

### Tes yang Harus Ada
- [ ] Unit test: pembuatan skema database baru berhasil tanpa error sintaks SQLite.
- [ ] Drift migration test: tes migrasi naik secara berantai dari skema v1 ke versi berikutnya menggunakan drift_dev migration verifier.
- [ ] Unit test: kueri indeks `(state, due)` pada `user_cards` terbukti menggunakan indeks SQLite (EXPLAIN QUERY PLAN).

### Observability yang Harus Ada
- [ ] Log eksekusi migrasi DB lokal tercatat saat aplikasi dibuka.
