# [M3-6b] Input Jawaban Ketik & Normalisasi Teks Jepang

**Milestone:** M3 — Flutter Inti (Offline)  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M3-6b` — Input Jawaban Ketik & Normalisasi Teks Jepang
- **Tujuan:** Mengimplementasikan input jawaban ketik dengan FTextField, proteksi komposisi IME, normalisasi Unicode NFKC, konversi katakana/hiragana, dan pencocokan accepted_answers.
- **Bagian Dokumen Acuan:** §3.4 (Facet recall), §5.2.1 (FTextField), §16.3 (Normalisasi teks Jepang & komposisi IME)
- **Input:** Input keyboard pengguna, field `accepted_answers` pada data item konten.
- **Output:** Widget `JpTextInput` di `apps/mobile/lib/ui/widgets/jp_text_input.dart` dan utilitas normalisasi `text_normalizer.dart`.

### Langkah Implementasi
1. Buat input field jawaban berbasis Forui `FTextField` (§5.2.1).
2. Penanganan Kritis Komposisi IME (§16.3): deteksi event IME keyboard; DILARANG mengevaluasi jawaban saat status keyboard pengguna masih aktif melakukan composing teks kana/kanji!
3. Implementasikan normalisasi teks Jepang (§16.3):
4.   - Normalisasi Unicode NFKC.
5.   - Hapus seluruh spasi (whitespace / full-width space).
6.   - Untuk facet pembacaan (reading), konversi katakana ke hiragana sebelum dibandingkan.
7.   - Tangani karakter vokal panjang (ー) dan kana kecil (っ, ゃ, ゅ, ょ).
8. Cocokkan hasil normalisasi terhadap daftar `accepted_answers` yang disediakan oleh data item konten (§16.3).
9. Sediakan visual feedback instan (benar/salah) menggunakan token warna `AppColors` tanpa delay.

### Tes yang Harus Ada
- [ ] Unit test normalisasi: variasi input (full-width vs half-width, katakana vs hiragana, spasi) terverifikasi cocok dengan accepted_answers.
- [ ] Widget test: penekanan tombol Enter saat IME masih composing TIDAK memicu evaluasi jawaban salah prematur.
- [ ] Unit test: penanganan vokal panjang dan huruf kecil kana dievaluasi tepat.

### Observability yang Harus Ada
- [ ] Metrik waktu durasi mengetik jawaban per kartu tercatat di log review.
