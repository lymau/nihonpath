# [M7-3] Penambahan Facet Lanjutan SRS (Listening, Kanji Writing, Grammar Production)

**Milestone:** M7 — N2–N1 dan Mock Test  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M7-3` — Penambahan Facet Lanjutan SRS (Listening, Kanji Writing, Grammar Production)
- **Tujuan:** Mengimplementasikan facet kartu SRS fase 2: listening (audio -> arti), writing kanji (tulis tangan kanji on-device), dan production tata bahasa (penyusunan kalimat / ketik output).
- **Bagian Dokumen Acuan:** §2 (Pelatihan fonetik & Output Swain), §3.4 (Facet ditunda ke fase 2), §5.5 (Tulisan tangan kanji)
- **Input:** Engine SRS klien M3-4 & M3-6, dataset kanji dan tata bahasa.
- **Output:** Facet handlers baru di `apps/mobile/lib/domain/srs/` dan komponen UI pendukung di `apps/mobile/lib/ui/widgets/`.

### Langkah Implementasi
1. Implementasikan Facet `listening` untuk item kosakata (§3.4):
2.   - Kartu memutar audio tanpa menampilkan teks Jepang terlebih dahulu;
3.   - Pengguna diminta memilih atau mengetik arti (audio -> makna);
4.   - Teks kanji dan furigana baru ditampilkan setelah pengguna menjawab.
5. Implementasikan Facet `writing` untuk karakter kanji N5–N1 (§3.4, §5.5):
6.   - Pengguna disajikan prompt makna kanji dan bacaan on/kun;
7.   - Pengguna menulis karakter kanji pada `HandwritingCanvas` menggunakan ML Kit Digital Ink Recognition on-device;
8.   - Animasi goresan KanjiVG ditampilkan sebagai referensi feedback pasca-menjawab.
9. Implementasikan Facet `production` untuk tata bahasa (§3.4):
10.   - Latihan menyusun blok kata menjadi kalimat utuh atau mengetik konjugasi kata kerja yang tepat dalam konteks kalimat.
11. Pastikan penomoran `card_id` deterministik tetap berlaku: `card_id = UUIDv5(NAMESPACE_CARD, item_external_key + ':' + facet)` sehingga facet baru tidak menduplikasi kartu lama (§3.4, §6.1).

### Tes yang Harus Ada
- [ ] Unit test: pembentukan card_id deterministik UUIDv5 untuk facet listening, writing, dan production.
- [ ] Widget test: kartu facet listening memutar audio dan menyembunyikan teks sebelum jawaban dinilai.
- [ ] Widget test: kanvas tulisan tangan kanji memvalidasi input goresan pengguna secara on-device.

### Observability yang Harus Ada
