# [M3-10] Onboarding, pengaturan, notifikasi lokal harian

**Milestone:** M3 — Flutter Inti (Offline)  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M3-10` — Onboarding, pengaturan, notifikasi lokal harian
- **Tujuan:** Mengimplementasikan alur layar /onboarding (guest mode langsung), layar /settings lengkap dengan dialog privasi/penghapusan akun, serta notifikasi pengingat harian flutter_local_notifications.
- **Bagian Dokumen Acuan:** §1 (Guest mode), §5.2 (flutter_local_notifications), §5.3 (/onboarding, /settings), §10.6, §12.2 (Persetujuan privasi & tombol hapus akun)
- **Input:** Settings DAO Drift DB, package `flutter_local_notifications`.
- **Output:** Layar `/onboarding` dan `/settings` di `apps/mobile/lib/features/`, dan notification service di `lib/core/`.

### Langkah Implementasi
1. Implementasikan layar `/onboarding`: pilihan target level (N5..N1), target kuota harian kartu baru, dan banner dialog persetujuan analitik privasi (UU PDP & GDPR, §12.2).
2. Aktifkan Guest Mode langsung tanpa mewajibkan registrasi atau input email (§1, §5.3).
3. Implementasikan layar `/settings` menggunakan `FItemGroup` dan `FItem` Forui (§5.2.1):
4.   - Konfigurasi target retensi FSRS (0.85 Santai, 0.90 Standar, 0.95 Ketat) (§2).
5.   - Konfigurasi kuota kartu baru harian (rentang 0..30) (§3.6).
6.   - Opsi tampilan furigana (selalu / di atas level / tidak) (§5.5).
7.   - Pengaturan bahasa UI (Indonesia / English) via locale switcher.
8.   - Tombol 'Hapus Akun' dengan konfirmasi eksplisit (WAJIB ADA sesuai kebijakan toko Apple & Google, §5.3, §12.2, §16.3).
9.   - Tautan permintaan 'Ekspor Data' (§12.2).
10. Konfigurasi `flutter_local_notifications`: jadwalkan notifikasi pengingat belajar harian lokal berdasarkan zona waktu lokal pengguna (§5.2, §15).

### Tes yang Harus Ada
- [ ] Integration test: pengguna baru dapat menyelesaikan onboarding langsung dalam guest mode tanpa form login.
- [ ] Unit test: perubahan preferensi di settings tersimpan ke database `user_settings` dan memicu update outbox sync.
- [ ] Unit test: notifikasi lokal dijadwalkan tepat pada jam yang ditentukan sesuai zona waktu lokal.

### Observability yang Harus Ada
- [ ] Event analitik produk: `onboarding_completed` dan `settings_changed` dipancarkan (§10.6).
- [ ] Log INFO saat jadwal notifikasi lokal diperbarui.

### Di Luar Cakupan (Out of Scope)
- Push notification jarak jauh dari server via FCM/APNs (hanya notifikasi lokal terjadwal di MVP).
- Paywall langganan (dikerjakan di M6-1).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ Guest mode WAJIB tersedia tanpa memaksa pendaftaran akun (§1, §5.3).
- ⚠️ Tombol 'Hapus Akun' WAJIB tersedia di aplikasi (kebijakan mutlak toko aplikasi) (§5.3, §12.2, §16.3).
- ⚠️ Persetujuan analitik wajib eksplisit diminta saat onboarding (§10.5, §12.2).
