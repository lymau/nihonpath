# [M2-1b] CLI Ingest KanjiVG & Tatoeba

## Task Brief

- **Task ID / Judul:** `M2-1b` — CLI Ingest KanjiVG & Tatoeba
- **Tujuan:** Mengembangkan modul CLI tools/content-cli untuk mem-parsing SVG urutan goresan KanjiVG dan kalimat contoh Tatoeba ke dalam kolam kandidat konten.
- **Bagian Dokumen Acuan:** §3.2 (Sumber data dan lisensi), §9.1 tahap 1 (Ingest), §14.1 (tools/content-cli)
- **Input:** Arsip file SVG KanjiVG dan corpus Tatoeba (dataset kalimat bahasa Jepang - Indonesia/Inggris).
- **Output:** CLI command `nihon-content ingest kanjivg` dan `nihon-content ingest tatoeba` yang menyimpan asset ke `content/_pool/strokes/` dan `content/_pool/sentences/`.

### Langkah Implementasi
1. Implementasikan parser untuk KanjiVG: sanitasi file SVG urutan goresan kanji/kana, ekstrak path strokes dan nomor urut goresan.
2. Format output SVG KanjiVG ke `content/_pool/strokes/{unicode}.svg` dengan metadata lisensi CC BY-SA 3.0 (§3.2).
3. Implementasikan parser untuk corpus Tatoeba: filter kalimat berbahasa Jepang yang memiliki terjemahan bahasa Indonesia (`id`) dan bahasa Inggris (`en`).
4. Format kalimat contoh Tatoeba ke YAML di `content/_pool/sentences/` menyertakan `tatoeba_id`, teks Jepang, terjemahan, dan atribusi lisensi CC BY 2.0 FR (atau CC0 jika berlaku, §3.2, §9.2).

### Tes yang Harus Ada
- [ ] Unit test: validasi sintaks XML/SVG hasil ekstraksi KanjiVG.
- [ ] Unit test: parser Tatoeba memadankan pasangan terjemahan ja-id dan ja-en dengan benar.
- [ ] Verifikasi setiap file output menyertakan metadata lisensi yang tepat.

### Observability yang Harus Ada
- [ ] Log ringkasan jumlah goresan SVG dan kalimat contoh yang berhasil diimpor.

### Di Luar Cakupan (Out of Scope)
- Tokenisasi Sudachi untuk kalimat Tatoeba (dikerjakan di M2-6b).
- Ingest JMdict/KANJIDIC2 (dikerjakan di M2-1a).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ Atribusi lisensi KanjiVG (CC BY-SA 3.0) dan Tatoeba (CC BY 2.0 FR) wajib dicatat (§3.2).
- ⚠️ SVG wajib disanitasi dari tag atau atribut script berbahaya.
