**Milestone:** M0 — Fondasi

**Area:** `infra`  

---

## Task Brief

- **Task ID / Judul:** `M0-3` — docker-compose lokal (Postgres, Redis, MinIO, OTel Collector, Grafana)
- **Tujuan:** Menyediakan lingkungan pengembangan lokal terpadu menggunakan docker-compose yang mencakup database, cache, storage, dan stack observability.
- **Bagian Dokumen Acuan:** §4.2 (Pilihan teknologi), §10.2, §10.3, §10.4, §14.2 (Lingkungan lokal)
- **Input:** Kebutuhan stack teknologi §4.2 dan §14.2.
- **Output:** File `docker-compose.yml`, direktori konfigurasi `docker/`, dan script `make up` / `npm run docker:up`.

### Langkah Implementasi
1. Buat `docker-compose.yml` yang menjalankan service: PostgreSQL 16 (dengan ekstensi `citext`), Redis (Alpine), MinIO (S3-compatible object storage), OpenTelemetry Collector, Prometheus, Loki, Tempo, dan Grafana.
2. Konfigurasi bucket MinIO awal (`nihonpath-packs`, `nihonpath-audio`) secara otomatis saat kontainer start.
3. Konfigurasi OTel Collector pipeline untuk menerima OTLP via gRPC/HTTP dan meneruskan metrik ke Prometheus, log ke Loki, dan trace ke Tempo.
4. Konfigurasi datasource Grafana siap pakai (Prometheus, Loki, Tempo).
5. Sediakan script automasi (misal `make up` atau npm script) dan data seed kecil untuk verifikasi.

### Tes yang Harus Ada
- [ ] Jalankan `docker-compose up -d`: semua kontainer berstatus healthy.
- [ ] Verifikasi pengiriman contoh span trace dummy ke OTel Collector dan pastikan trace muncul di antarmuka Grafana.

### Observability yang Harus Ada
- [ ] Healthcheck aktif untuk setiap service di docker-compose.
- [ ] Log kontainer teragregasi rapi.

### Di Luar Cakupan (Out of Scope)
- Deployment ke server cloud staging/produksi.
- Isi data kurikulum lengkap (hanya dummy seed kecil).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ PostgreSQL minimal versi 16 (§4.2).
- ⚠️ Stack observability harus memakai standar terbuka OpenTelemetry (§4.2).
- ⚠️ Dilarang membocorkan password atau kredensial produksi ke file docker-compose lokal.
