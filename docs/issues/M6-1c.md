# [M6-1c] Penegakan Entitlement Server pada Paket Konten Premium

**Milestone:** M6 — Rilis v1  
**Estimasi Ukuran:** M  
**Area:** `backend`  

---

## Task Brief

- **Task ID / Judul:** `M6-1c` — Penegakan Entitlement Server pada Paket Konten Premium
- **Tujuan:** Mengimplementasikan penegakan entitlement server-side pada pembuatan URL unduhan paket premium (N4–N1, passages, audio offline).
- **Bagian Dokumen Acuan:** §6.3 (content_packs.is_premium), §8.2 (download-url), §12.1 (Proteksi konten premium), §13 (Freemium: N5 gratis, N4-N1 premium)
- **Input:** Tabel `content_packs`, tabel `subscriptions`, service presigned URL S3.
- **Output:** Logika proteksi entitlement di `apps/api/src/modules/content/content.service.ts`.

### Langkah Implementasi
1. Kaitkan pengecekan entitlement langganan pada endpoint `GET /v1/content/packs/:id/download-url` (§8.2, §13):
2.   - Baca atribut `is_premium` pada paket konten yang diminta dari tabel `content_packs`.
3.   - Model freemium (§13): Level 0 (Kana) dan Level N5 gratis untuk seluruh pengguna (`is_premium = false`).
4.   - Level N4 s/d N1, mock test lengkap, dan paket audio/passages offline tingkat lanjut ditandai `is_premium = true`.
5.   - Jika paket berstatus premium, verifikasi tabel `subscriptions` untuk `user_id` pemanggil: pastikan ada record langganan aktif (`expires_at > now()`).
6.   - Jika pengguna tidak memiliki entitlement valid, tolak dengan status 403 Forbidden dan kode error RFC 9457 `ENTITLEMENT_REQUIRED` (§8.4).
7.   - Jika valid, generate URL unduhan S3/CloudFront bertanda tangan (presigned URL) berumur pendek.

### Tes yang Harus Ada
- [ ] Security test: pengguna gratis berhasil mengunduh paket core dan audio Level N5.
- [ ] Security test: pengguna gratis menerima error ENTITLEMENT_REQUIRED saat mencoba meminta URL unduh paket Level N4 atau N3.
- [ ] Security test: pengguna dengan subscription aktif berhasil memperoleh download-url bertanda tangan untuk paket premium.

### Observability yang Harus Ada
- [ ] Log WARN saat akses paket premium ditolak karena ketiadaan entitlement.
- [ ] Metrik Prometheus counter penolakan entitlement.

### Di Luar Cakupan (Out of Scope)
- Enkripsi DRM biner pada file audio (perlindungan cukup via presigned URL dan rate limit sesuai §12.1).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ Server WAJIB menegakkan entitlement pada URL unduh paket; dilarang mengandalkan proteksi klien semata (§12.1, §13).
- ⚠️ Level 0 dan N5 WAJIB tetap gratis (§13).
- ⚠️ Presigned URL WAJIB berumur pendek (§12.1).
