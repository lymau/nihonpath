# [M8-5] Adaptasi Layout Tablet dan Widget Layar Utama

**Milestone:** M8 — Fase 3  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M8-5` — Adaptasi Layout Tablet dan Widget Layar Utama
- **Tujuan:** Mengembangkan antarmuka responsif adaptif untuk perangkat tablet/iPad dan widget layar utama (Home Screen Widgets) untuk Android dan iOS.
- **Bagian Dokumen Acuan:** §5.6 (Aksesibilitas & tata letak), §15 (M8 Fase 3)
- **Input:** Desain antarmuka Forui tablet, sistem widget OS (Android AppWidget & iOS WidgetKit).
- **Output:** Layout adaptif tablet di `apps/mobile/` dan native widgets di `android/` & `ios/`.

### Langkah Implementasi
1. Implementasikan tata letak adaptif (adaptive two-pane / split view layout) untuk layar tablet (lebar layar > 600 dp) pada menu Library, Pelajaran, dan Pengaturan (§15).
2. Kembangkan Home Screen Widget untuk Android (Glance / RemoteViews) dan iOS (WidgetKit):
3.   - Menampilkan jumlah review yang jatuh tempo hari ini secara sekilas;
4.   - Menampilkan streak belajar aktif pengguna;
5.   - Tombol aksi cepat untuk langsung membuka sesi review di aplikasi.
6. Sinkronisasikan data widget dari database SQLite lokal Drift melalui shared container / background service.

### Tes yang Harus Ada
- [ ] Widget test: antarmuka beralih mulus antara single-pane di ponsel dan two-pane di tablet.
- [ ] Platform test: widget Android dan iOS menampilkan angka review due yang akurat sesuai database lokal.

### Observability yang Harus Ada
- [ ] Log INFO saat data widget diperbarui oleh background task.

### Di Luar Cakupan (Out of Scope)
- Aplikasi web desktop (eksplisit non-goals MVP/v1 sesuai §1).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ Desain tablet tetap wajib mengikuti token desain Forui (§5.2.1).
- ⚠️ Widget dilarang mengakses jaringan secara independen (wajib membaca dari data lokal Drift) (§4.3).
