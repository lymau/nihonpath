# [M3-3b] Content Pack Installer & FTS Seeder

**Milestone:** M3 — Flutter Inti (Offline)  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M3-3b` — Content Pack Installer & FTS Seeder
- **Tujuan:** Mengimplementasikan ekstraksi zip atomik, impor data paket ke SQLite Drift, populasi indeks pencarian FTS5, dan mekanisme rollback otomatis jika gagal.
- **Bagian Dokumen Acuan:** §5.2 (archive), §5.5 (Pencarian FTS5), §6.2 (pack_state, fts_items), §9.3 (Distribusi paket)
- **Input:** File zip paket konten yang terverifikasi SHA-256 dari M3-3a.
- **Output:** Class `ContentPackInstaller` di `apps/mobile/lib/data/content_pack/`.

### Langkah Implementasi
1. Implementasikan fungsi ekstraksi file zip menggunakan paket `archive` ke direktori lokal terisolasi.
2. Buka transaksi database Drift SQLite atomik (§9.3):
3.   - Baca `items.jsonl` dan `lessons.json` secara streaming/batch.
4.   - Upsert ke tabel `content_items`, `lessons`, dan `lesson_items`.
5.   - Ekstrak aset audio (`.opus`) dan SVG goresan (`.svg`) ke storage aplikasi lokal.
6.   - Populasi virtual table `fts_items` (FTS5) atas kana, kanji, romaji, dan arti untuk pencarian offline (§5.5, §6.2).
7.   - Catat riwayat instalasi ke tabel `pack_state` (pack_id, kind, level, version, sha256, installed_at).
8. Implementasikan rollback atomik (§9.3): jika terjadi exception/kegagalan di tengah proses pemasangan, batalkan transaksi database, hapus file parsial, dan kembalikan versi paket aktif ke versi lama.
9. Pastikan proses ekstraksi dan instalasi berjalan di background isolate agar UI tidak membeku (unresponsive).

### Tes yang Harus Ada
- [ ] Unit test: ekstraksi dan impor paket uji berhasil mengisi tabel `content_items` dan indeks `fts_items`.
- [ ] Integration test (fault injection): simulasi file corrupt di tengah instalasi memicu rollback atomik tanpa merusak database lama.
- [ ] Unit test: pencarian kata pada `fts_items` mengembalikan hasil yang relevan.

### Observability yang Harus Ada
- [ ] Log INFO mencatat durasi instalasi paket, jumlah item diimpor, dan versi paket.
- [ ] Metrik error jika instalasi mengalami rollback.

### Di Luar Cakupan (Out of Scope)

- ⚠️ Ekstraksi dan parsing data dilarang memblokir UI thread (jalankan di isolate) (§1 NFR).
