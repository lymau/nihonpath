# [M8-2] Latihan Shadowing dengan Rekaman Suara

**Milestone:** M8 — Fase 3  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M8-2` — Latihan Shadowing dengan Rekaman Suara
- **Tujuan:** Mengimplementasikan fitur latihan shadowing audio: memutar audio referensi penutur asli dan merekam suara pengguna untuk perbandingan mandiri tanpa skoring otomatis.
- **Bagian Dokumen Acuan:** §2 (Pelatihan fonetik variabilitas tinggi & shadowing), §15 (M8 Fase 3)
- **Input:** Audio referensi kalimat/kata dari paket passages/audio, mikrofon perangkat mobile.
- **Output:** Widget `ShadowingPlayer` di `apps/mobile/lib/ui/widgets/shadowing_player.dart` dan layar latihan shadowing.

### Langkah Implementasi
1. Rancang antarmuka latihan shadowing:
2.   - Memutar cuplikan audio kalimat/dialog penutur asli (§2);
3.   - Mengaktifkan rekaman suara pengguna lokal secara sinkron atau bertahap;
4.   - Memutar ulang rekaman pengguna berdampingan dengan audio penutur asli untuk evaluasi mandiri (self-assessment).
5. Kebijakan Tanpa Skoring Otomatis (§15, M8): TANPA penilaian ucapan real-time atau skoring algoritmik (menghindari kebohongan akurasi speech scoring).
6. Kebijakan Privasi (§12.1): file rekaman suara pengguna HANYA disimpan sementara di disk lokal perangkat dan DILARANG diunggah ke server.

### Tes yang Harus Ada
- [ ] Widget test: audio player memutar referensi dan kontrol perekam audio berfungsi.
- [ ] Integration test: file rekaman suara sementara dapat diputar ulang secara lokal.
- [ ] Security check: rekaman audio terbukti tidak pernah dikirim ke jaringan server backend.

### Observability yang Harus Ada
- [ ] Event analitik produk saat pengguna menyelesaikan latihan shadowing.

### Di Luar Cakupan (Out of Scope)
- Speech-to-text atau penilaian pelafalan otomatis AI (eksplisit dilarang sesuai §1 Non-goals & §15 M8).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ TANPA SKORING OTOMATIS pada runtime (§15 M8).
- ⚠️ DILARANG mengunggah audio rekaman pengguna ke server (privasi §12.1, §15).
