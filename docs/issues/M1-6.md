## Task Brief

- **Task ID / Judul:** `M1-6` — Modul content: manifest (ETag) + download-url bertanda tangan
- **Tujuan:** Mengimplementasikan endpoint manifest paket konten dengan dukungan ETag caching serta endpoint download-url bertanda tangan dengan verifikasi entitlement paket premium.
- **Bagian Dokumen Acuan:** §6.3 (content_packs), §8.2 (Konten), §9.3 (Anggaran ukuran dan distribusi), §12.1 (Proteksi konten), §13 (Entitlement)
- **Input:** Tabel `content_packs`, service S3 presigned URL, service entitlement billing.
- **Output:** Module content di `apps/api/src/modules/content/` dengan endpoint `GET /v1/content/manifest` dan `GET /v1/content/packs/:id/download-url`.

### Langkah Implementasi
1. Endpoint `GET /v1/content/manifest?level={0..5}`: query paket konten aktif dari tabel `content_packs` (id, level, kind, version, sha256, size_bytes, is_premium).
2. Hitung ETag berdasarkan hash representasi manifest; jika request mengirim header `If-None-Match` yang cocok, kembalikan HTTP 304 Not Modified (§8.2).
3. Endpoint `GET /v1/content/packs/:id/download-url`: ambil record paket konten. Jika `is_premium == true`, periksa entitlement aktif pengguna.
4. Jika paket premium dan pengguna tidak memiliki langganan aktif, kembalikan error RFC 9457 dengan code `ENTITLEMENT_REQUIRED` (§8.4, §13).
5. Jika diizinkan (atau paket gratis), buat presigned download URL S3/CDN berumur pendek (misal 15 menit) dan kembalikan ke klien.

### Tes yang Harus Ada
- [ ] Integration test: `GET /v1/content/manifest` mengembalikan header ETag, dan request ulang dengan `If-None-Match` mengembalikan status 304.
- [ ] Security test: akses `download-url` paket gratis berhasil mengembalikan URL bertanda tangan.
- [ ] Security test: akses `download-url` paket premium tanpa entitlement mengembalikan 403 Forbidden dengan kode `ENTITLEMENT_REQUIRED`.

### Observability yang Harus Ada
- [ ] Logging INFO untuk setiap permintaan download URL (mencatat user_hash dan pack_id).
- [ ] Metrik Prometheus HTTP duration untuk endpoint konten.
