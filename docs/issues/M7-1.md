# [M7-1] Engine Mock Test bergaya JLPT

**Milestone:** M7 — N2–N1 dan Mock Test  
**Estimasi Ukuran:** M  
**Area:** `mobile`  

---

## Task Brief

- **Task ID / Judul:** `M7-1` — Engine Mock Test bergaya JLPT
- **Tujuan:** Mengimplementasikan engine mock test bergaya JLPT pada layar /mocktest/:id dengan timer ujian, 3 seksi tes terstruktur, skor estimasi persentase dengan disclaimer eksplisit, dan sinkronisasi test_attempts.
- **Bagian Dokumen Acuan:** §3.7 (Mock test bergaya JLPT), §5.3 (/mocktest/:id), §6.2 (Tabel test_attempts), §16.3 (Disclaimer skor & batasan resmi)
- **Input:** Data paket ujian `pack-*-tests-v1.zip` dari content pipeline.
- **Output:** Layar `/mocktest/:id` di `apps/mobile/lib/features/mocktest/`, engine test di `apps/mobile/lib/domain/tests/`, dan test attempt outbox sync.

### Langkah Implementasi
1. Implementasikan engine ujian di `apps/mobile/lib/domain/tests/`:
2.   - Struktur 3 seksi standar ujian JLPT (§3.7): 文字・語彙・文法 (Kosakata & Tata Bahasa), 読解 (Membaca), dan 聴解 (Mendengarkan).
3.   - Timer hitung mundur ujian yang ketat sesuai batas waktu level yang diuji.
4.   - Manajemen state jawaban pengguna, navigasi antar butir soal, dan penanda ragu-ragu.
5. Implementasikan layar antarmuka `/mocktest/:id` menggunakan Forui widgets (`FScaffold`, `FCard`, `FButton`) (§5.2.1).
6. Implementasikan Layar Hasil Ujian (§3.7, §16.3):
7.   - Hitung persentase jawaban benar per seksi dan total.
8.   - WAJIB SERTAKAN DISCLAIMER EKSPLISIT (§3.7, §16.3): skor resmi JLPT menggunakan skala terekuivalensi (scaled scores / Item Response Theory); aplikasi ini hanya menampilkan estimasi persentase dan TIDAK mengklaim atau menjamin kelulusan resmi JLPT.
9. Simpan riwayat hasil ujian ke tabel lokal Drift `test_attempts` (id, test_id, started_at, finished_at, score_json) dan masukkan entri ke outbox sync (§6.2, §7.3).
10. Pancarkan event analitik: `mocktest_completed` (§10.6).

### Tes yang Harus Ada
- [ ] Unit test: engine timer menghitung mundur dan otomatis mengakhiri ujian saat waktu habis.
- [ ] Unit test: kalkulasi skor persentase benar per seksi akurat.
- [ ] Widget test: layar hasil menampilkan disclaimer resmi bahwa skor merupakan estimasi dan bukan sertifikat resmi JLPT.
- [ ] Integration test: data percobaan tersimpan di tabel `test_attempts` dan dicatat di outbox.

### Observability yang Harus Ada
- [ ] Event analitik `mocktest_completed` mencatat durasi, skor persentase, dan ID tes.

### Di Luar Cakupan (Out of Scope)
- Penerbitan sertifikat resmi (aplikasi hanya alat latihan belajar mandiri).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ Hasil ujian WAJIB menampilkan disclaimer jelas bahwa skor adalah estimasi persentase, bukan skor resmi JLPT (§3.7, §16.3).
- ⚠️ DILARANG mengklaim peluang lulus JLPT tanpa data valid (§2, §16.3, §17).
- ⚠️ DILARANG menyalin soal resmi JLPT yang berhak cipta (§0 Aturan 5).
