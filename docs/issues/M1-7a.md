# [M1-7a] Sync Push (POST /v1/sync/push) & Serialisasi Transaksi

**Milestone:** M1 — Backend Inti

## Task Brief

- **Task ID / Judul:** `M1-7a` — Sync Push (POST /v1/sync/push) & Serialisasi Transaksi
- **Tujuan:** Mengimplementasikan endpoint push sinkronisasi dengan validasi payload, serialisasi row-lock user_sync_state, evaluasi aturan merge LWW, dan penomoran user_seq gapless.
- **Bagian Dokumen Acuan:** §6.3 (user_sync_state, user_cards, review_logs), §7.1, §7.2, §7.3 (Aturan merge), Lampiran C.2 (Handler push server)
- **Input:** Payload push batch dari klien (max 200 ops, max 512 KB), koneksi PostgreSQL Kysely.
- **Output:** Endpoint `POST /v1/sync/push` di `apps/api/src/modules/sync/` dan service push sinkronisasi.

### Langkah Implementasi
1. Validasi ukuran request: jika ops > 200 atau body > 512 KB, segera tolak dengan status 413 Payload Too Large (§7.2, Lampiran C.2).
2. Buka transaksi DB: jalankan serialisasi per pengguna persis sesuai Lampiran C.2:
3.   `INSERT INTO user_sync_state(user_id) VALUES (userId) ON CONFLICT DO NOTHING;`
4.   `SELECT last_seq FROM user_sync_state WHERE user_id = userId FOR UPDATE;`
5. Validasi waktu `reviewed_at` pada op `review_log`: harus dalam rentang [now - 400 hari, now + 1 hari]. Jika melanggar, tandai op sebagai rejected dengan code `SYNC_CLOCK_INVALID` (§6.3, §8.4).
6. Evaluasi keputusan op tanpa langsung menulis: `review_log` (duplicate bila ID sudah ada, applied bila baru); `card_state` (aturan LWW §7.3: menang jika `last_review_at` lebih baru; seri -> `reps` lebih besar; seri -> `updated_at` lebih baru; applied bila menang, duplicate bila kalah/identik); `settings`, `lesson_progress`, `test_attempt` sesuai §7.3.
7. Hitung n = jumlah op yang applied. Nomor seq = last_seq + 1 .. last_seq + n (berurutan tanpa celah).
8. Tulis seluruh op applied dengan nomor `user_seq` tersebut ke database dalam transaksi yang sama.
9. Update `user_sync_state SET last_seq = last_seq + n WHERE user_id = userId;`
10. Commit transaksi dan kembalikan `{ results: [{op_id, status: accepted|duplicate|rejected, code?}], next_cursor, server_time }`.
