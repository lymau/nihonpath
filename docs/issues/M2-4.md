# [M2-4] Pipeline audio TTS (multi-suara, Opus)

**Milestone:** M2 — Content Pipeline dan Konten Awal  
**Estimasi Ukuran:** M  
**Area:** `content`  

---

## Task Brief

- **Task ID / Judul:** `M2-4` — Pipeline audio TTS (multi-suara, Opus)
- **Tujuan:** Mengembangkan pipeline otomasi pra-render audio berbasis cloud neural TTS dengan minimal 2 variasi suara, format Opus 32–48 kbps, dan pelacakan biaya.
- **Bagian Dokumen Acuan:** §2 (Pelatihan fonetik variabilitas tinggi), §3.2 (Lisensi ToS TTS), §5.5 (Audio pra-render), §9.1 tahap 3 (Enrichment), §9.3 (Anggaran audio)
- **Input:** Teks kata dan kalimat contoh dari `content/`, API key cloud TTS (Google Cloud TTS / Azure Speech / AWS Polly).
- **Output:** CLI command `nihon-content audio generate`, file audio `.opus` di `content/assets/audio/`, dan log pelacakan biaya.

### Langkah Implementasi
1. Implementasikan modul generator audio di `tools/content-cli/` yang memanggil API neural TTS resmi.
2. Wajibkan minimal 2 profil suara berbeda per item: 1 suara perempuan (`f1`) dan 1 suara laki-laki (`m1`) untuk memenuhi prinsip variabilitas fonetik (§2, §5.5, §9.2).
3. Konversi/encode output audio ke format Opus (atau AAC) dengan bitrate efisien 32–48 kbps menggunakan `ffmpeg` guna memenuhi anggaran ukuran paket audio < 60 MB (§5.5, §9.3).
4. Simpan audio dengan pola path stabil: `audio/vocab_{id}_{voice}.opus` dan kaitkan ke file YAML sumber konten.
5. Implementasikan tracking biaya API TTS (hitung estimasi biaya per 1.000 karakter/item yang di-render) dan simpan laporan ringkasan biaya.
6. Pastikan verifikasi kepatuhan ToS penyedia TTS terkait izin penyimpanan (caching) dan redistribusi audio offline dalam aplikasi (§3.2).

### Tes yang Harus Ada
- [ ] Unit test: generator audio menghasilkan minimal 2 file audio (f1 dan m1) untuk setiap kata uji.
- [ ] Unit test: verifikasi bitrate audio berada dalam rentang 32–48 kbps dan format kontainer Opus valid.
- [ ] Verifikasi estimasi kalkulasi biaya tercatat akurat di log output.

### Observability yang Harus Ada
- [ ] Log mencatat jumlah file audio dibuat, durasi pemanggilan API, total kuota karakter TTS terpakai, dan kalkulasi biaya.

### Di Luar Cakupan (Out of Scope)
- Pemutaran audio di aplikasi mobile (dikerjakan di M3-6 menggunakan `just_audio`).
- Penilaian ucapan real-time (dikecualikan dari MVP sesuai §1 Non-goals).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ Setiap vocab WAJIB memiliki minimal 2 suara pra-render (laki-laki dan perempuan) (§2, §5.5, §9.2).
- ⚠️ Format audio WAJIB Opus/AAC 32–48 kbps untuk menjaga ukuran paket (§5.5).
- ⚠️ Periksa ToS cloud TTS terkait hak redistribusi audio (§3.2).
