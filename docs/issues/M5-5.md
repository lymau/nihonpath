# [M5-5] Latihan restore backup

**Milestone:** M5 — Observability, Hardening, Beta Tertutup  
**Estimasi Ukuran:** S  
**Area:** `security-ops`  

---

## Task Brief

- **Task ID / Judul:** `M5-5` — Latihan restore backup
- **Tujuan:** Melakukan latihan simulasi pemulihan bencana (disaster recovery drill) dari backup database PostgreSQL PITR dan mendokumentasikan pencapaian target RPO/RTO.
- **Bagian Dokumen Acuan:** §11.4 (Backup dan pemulihan bencana), §15 (M5-5), Lampiran B (Checklist pra-rilis)
- **Input:** Arsip WAL kontinu PostgreSQL dan snapshot mingguan di environment staging.
- **Output:** Laporan hasil latihan pemulihan bencana di `docs/runbooks/dr-recovery-report.md`.

### Langkah Implementasi
1. Lakukan latihan restorasi database (DR drill) secara langsung di environment staging (§11.4):
2.   - Simulasikan insiden kehilangan data pada waktu T.
3.   - Eksekusi Point-In-Time Recovery (PITR) dari arsip WAL kontinu ke instance database pengujian baru.
4. Ukur dan catat metrik pemulihan riil:
5.   - Ukur RPO (Recovery Point Objective): verifikasi kehilangan data kurang dari 5 menit (§11.4).
6.   - Ukur RTO (Recovery Time Objective): verifikasi waktu dari insiden hingga database pulih dan dapat melayani query kurang dari 1 jam (§11.4).
7. Verifikasi integritas data hasil restore: lakukan query konsistensi tabel `users`, `user_sync_state`, `user_cards`, dan partisi `review_logs`.
8. Tulis laporan resmi hasil simulasi pemulihan di `docs/runbooks/dr-recovery-report.md` (Catatan §11.4: backup yang belum pernah diuji dianggap tidak ada).

### Tes yang Harus Ada
- [ ] Integritas database hasil restorasi terbukti identik dengan titik waktu pemulihan (PITR).
- [ ] RPO terukur ≤ 5 menit dan RTO terukur ≤ 1 jam memenuhi standar §11.4.

### Observability yang Harus Ada
- [ ] Log dan metrik waktu proses restore tercatat dalam laporan.

### Di Luar Cakupan (Out of Scope)
- Simulasi failover multi-region otomatis (MVP menggunakan arsitektur single-region multi-AZ dengan salinan backup ke Singapura sesuai §11.4).

### Aturan Teknis Ketat & Larangan (§0, §4.3, §10, §12, §16)
- ⚠️ Target pemulihan WAJIB RPO ≤ 5 menit dan RTO ≤ 1 jam (§11.4).
- ⚠️ Latihan restore backup WAJIB terdokumentasi; backup yang tidak diuji dianggap tidak ada (§11.4).
